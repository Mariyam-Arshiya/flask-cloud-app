Setup Required

Firebase key is missing. Follow these steps to connect InkReal to your Firebase project.

Step 1: Create Firebase project

  1. Go to Firebase Console
  2. Click Add project, name it, disable Analytics, create

Step 2: Enable Firestore

  1. Left sidebar → Build → Firestore Database
  2. Click Create database, select Test mode, pick a location, enable

Step 3: Download service account key

  1. Click gear icon → Project settings
  2. Tab: Service accounts
  3. Click Generate new private key, download the JSON file

Step 4: Place the key

Rename the downloaded file to serviceAccountKey.json and place it in your project root.

PowerShell command:

Move-Item "C:\Users\DELL\Downloads\*firebase-adminsdk*.json" ".\serviceAccountKey.json"

Step 5: Set Firestore security rules

In Firebase Console → Firestore → Rules, paste this and publish:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      allow read: if true;
      allow write: if false;
    }
    match /posts/{postId} {
      allow read: if resource.data.hidden == false || resource.data.hidden == null;
      allow write: if false;
      match /comments/{commentId} {
        allow read: if true;
        allow write: if false;
      }
      match /revisions/{revisionId} {
        allow read: if true;
        allow write: if false;
      }
    }
    match /reports/{reportId} {
      allow read, write: if false;
    }
  }
}

Note: Since Flask uses admin SDK, it bypasses these rules. This locks down direct client access.

Step 6: Restart

python app.py

You should see Firebase initialized successfully. Then go back home.
